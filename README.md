# 📋 TaskFlow (Offline Edition)

A sleek, modern, drag-and-drop Kanban board designed for personal task management without the need for a backend server. 

TaskFlow allows users to visually organize their workflow by moving tasks through "To Do", "In Progress", and "Done" stages.

## ✨ Key Features

* **Drag-and-Drop Interface:** Easily move tasks between columns with native HTML5 drag-and-drop mechanics.
* **Instant Task Creation:** Quickly add new action items to your "To Do" list.
* **Data Persistence:** Uses Browser `localStorage` to save your board state. Your tasks remain exactly where you left them, even after closing the browser!
* **Glassmorphism UI:** Built with a clean, dark-themed, responsive design using Tailwind CSS.
* **Zero Backend Required:** Runs entirely in the browser for maximum speed and privacy.

## 🛠️ Tech Stack

* **Frontend:** HTML5, Vanilla JavaScript
* **Styling:** Tailwind CSS (via CDN)
* **Storage:** Browser Local Storage

## 🚀 How to Run

1. Download or clone this repository.
2. Locate the `index.html` file.
3. Double-click the file to open it in any modern web browser.
4. Start organizing your tasks!
